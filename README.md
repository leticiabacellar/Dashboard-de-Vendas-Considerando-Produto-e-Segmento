## 📌 Sobre o Projeto

Este projeto consiste em um **Dashboard de Vendas** desenvolvido no **Power BI**, composto por **12 páginas interativas**, que apresentam uma análise completa dos indicadores comerciais da empresa.

O dashboard foi criado para fornecer uma visão estratégica das vendas sob diferentes perspectivas, como faturamento, lucro, produtos, segmentos de clientes, países, unidades vendidas e evolução temporal. Com uma navegação intuitiva e filtros dinâmicos, é possível explorar os dados em diferentes níveis de detalhamento, auxiliando na tomada de decisões baseadas em dados.

---

## 🚀 Funcionalidades

- 💰 Acompanhamento do faturamento total
- 📈 Análise do lucro obtido
- 📦 Desempenho por produto
- 🌎 Comparativo de vendas por país
- 👥 Análise por segmento de clientes
- 📅 Evolução das vendas por mês e ano
- 📊 Média do preço de venda por produto
- 📦 Quantidade de unidades vendidas
- 📈 Comparativos entre períodos
- 🎯 Indicadores estratégicos (KPIs)
- 🎛️ Segmentações dinâmicas para exploração dos dados
- 📑 Navegação entre **12 páginas** de análises

---

## 📊 Indicadores Disponíveis

| Indicador | Descrição |
|-----------|-----------|
| Vendas Totais | Valor total faturado |
| Lucro Total | Resultado financeiro obtido nas vendas |
| Unidades Vendidas | Quantidade total de produtos vendidos |
| Vendas por Produto | Participação de cada produto no faturamento |
| Média do Preço de Venda | Valor médio de venda por produto |
| Lucro por País | Distribuição do lucro entre os países |
| Vendas por País | Comparativo de vendas por localização |
| Vendas por Segmento | Participação dos segmentos de clientes |
| Evolução Mensal | Comportamento das vendas ao longo do tempo |
| Comparativo Anual | Análise da evolução entre diferentes anos |

## 📷 Visual do Dashboard

Este projeto é composto por **12 páginas**, cada uma dedicada à análise de um aspecto específico das vendas.

Entre as principais análises disponíveis estão:

- 📈 Indicadores de faturamento e lucro
- 📦 Desempenho dos produtos
- 🌍 Vendas e lucro por país
- 👥 Segmentação dos clientes
- 📅 Evolução das vendas ao longo do tempo
- 💲 Média do preço de venda
- 📊 Comparativos entre períodos
- 🎯 Indicadores estratégicos para apoio à tomada de decisão

---

## 📈 Objetivos do Dashboard

- Monitorar o desempenho das vendas.
- Acompanhar o faturamento e o lucro da empresa.
- Identificar os produtos com melhor desempenho.
- Comparar o desempenho entre países.
- Analisar os segmentos de clientes.
- Avaliar a evolução das vendas ao longo do tempo.
- Apoiar gestores na tomada de decisões estratégicas através de indicadores visuais.

## ▶️ Como Utilizar

1. Faça o download do arquivo `.pbix`.
2. Abra o projeto no **Power BI Desktop**.
3. Atualize a fonte de dados, caso necessário.
4. Navegue entre as **12 páginas** utilizando as abas do relatório.
5. Utilize os filtros para explorar diferentes perspectivas das vendas.
